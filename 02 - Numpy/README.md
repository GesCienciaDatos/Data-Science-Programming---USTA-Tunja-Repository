# Módulo 02: Cálculo Numérico con NumPy

Bienvenido al segundo módulo de **Programación para Ciencia de Datos (USTA Tunja)**. En esta lección aprenderás a usar NumPy, la librería fundamental para el procesamiento numérico y algebraico de alto rendimiento en Python. Todo modelo de Machine Learning funciona con tensores de NumPy en su núcleo.

## 🎯 Objetivos de aprendizaje

En este segundo módulo sentaremos las bases fundamentales del cálculo numérico, con un enfoque 100% orientado al análisis y la Ciencia de Datos. El material está organizado de forma progresiva en los siguientes cuadernos interactivos:

1. **[Introducción a NumPy](00_Introduccion_Numpy.ipynb)**: ¿Qué es NumPy, qué diferencia tiene con las listas nativas y por qué es tan rápido?
2. **[Creación de Arrays en NumPy](01_Creacion_de_Arrays_Numpy.ipynb)**: Funciones clave como `zeros`, `ones`, `linspace` y `arange`. Tipos de datos matemáticos (`dtype`) y atributos principales (`ndim`, `shape`).
3. **[Operaciones con Arrays](02_Operaciones_con_Arrays_Numpy.ipynb)**: Operaciones matemáticas elemento a elemento, el poderoso concepto de *Broadcasting*, funciones de agregación y álgebra matricial.
4. **[Indexación y Slicing de Arrays](03_Indexacion_y_Slicing_Numpy.ipynb)**: Cómo filtrar, rebanar y aplicar indexación mágica (*Fancy Indexing*) y Máscaras Booleanas.
5. **[Remodelación de Arrays (Reshaping)](04_Reshaping_Numpy.ipynb)**: Manipulando las dimensiones físicas de la memoria (`flatten` vs `ravel`) y usando dimensiones comodines (`-1`).
6. **[Concatenación y Apilamiento de Arrays](05_Concatenacion_Numpy.ipynb)**: Combinando y apilando bases de datos en los ejes existentes o creando dimensiones nuevas (`stack` vs `concatenate`).
7. **[Temas Avanzados: Aleatorios, Únicos y Dimensiones](06_Temas_Avanzados_Numpy.ipynb)**: Generadores pseudo-aleatorios, análisis estadístico de frecuencias y uso de `expand_dims` / `squeeze`.
