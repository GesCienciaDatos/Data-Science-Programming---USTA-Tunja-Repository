# Módulo 2: Computación Científica con NumPy

Este módulo introduce la librería NumPy, el estándar para la computación científica y matricial en Python.

## Contenido

- Creación y manipulación de Arrays ($N$-dimensionales)
- Indexación, Slicing y Filtrado Booleano
- Operaciones matemáticas vectorizadas y Broadcasting
- Álgebra Lineal y Funciones Universales (ufuncs)
