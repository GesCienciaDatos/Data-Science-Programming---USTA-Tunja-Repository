# Módulo 2: Computación Científica con NumPy

Este módulo introduce la biblioteca NumPy, el estándar de facto para la computación numérica, vectorial y matricial de alto rendimiento en Python.

## Contenido

1. **[Introducción a NumPy](00_Introduccion_Numpy.ipynb)**: Estructura de memoria contigua en C, ndarrays y ventajas frente a listas estándar.
2. **[Creación de Arrays en NumPy](01_Creacion_de_Arrays_Numpy.ipynb)**: Funciones de fábrica (`zeros`, `ones`, `arange`, `linspace`), atributos y tipos de datos (`dtype`).
3. **[Operaciones con Arrays](02_Operaciones_con_Arrays_Numpy.ipynb)**: Operaciones vectorizadas, funciones universales (`ufuncs`) y reglas de *Broadcasting*.
4. **[Indexación y Slicing](03_Indexacion_y_Slicing_Numpy.ipynb)**: Segmentación multidimensional, vistas vs copias, máscaras booleanas y Fancy Indexing.
5. **[Remodelación de Arrays (Reshaping)](04_Reshaping_Numpy.ipynb)**: Modificación dimensional con `reshape`, aplanado (`ravel`/`flatten`) y comodín `-1`.
6. **[Concatenación y Apilamiento](05_Concatenacion_Numpy.ipynb)**: Apilamiento horizontal (`hstack`), vertical (`vstack`) y concatenación en múltiples ejes.
7. **[Temas Avanzados: Aleatorios, Únicos y Dimensiones](06_Temas_Avanzados_Numpy.ipynb)** 🧗: Generación pseudo-aleatoria moderna, frecuencias con `np.unique` y manipulación de dimensiones (`expand_dims`/`squeeze`).
