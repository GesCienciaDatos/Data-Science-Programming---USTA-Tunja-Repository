# Data Science Programming - USTA Tunja

Este repositorio contiene el material docente utilizado en las sesiones de laboratorio de la asignatura **Programación para Ciencia de Datos** en la **Universidad Santo Tomás (Sede Tunja)**.

Dentro de cada directorio se encuentra un *notebook* teórico detalladamente comentado sobre el tema correspondiente, junto con una carpeta de ejercicios (`homework`) que contiene actividades prácticas y sus respectivas soluciones.

**Índice de Contenidos**

* **01 - Python**
  * Conceptos básicos de programación y Python
  * Variables, tipos de datos, listas y tuplas
  * Operadores básicos, condicionales y bucles
  * Funciones, diccionarios, clases y objetos
  * Operaciones con cadenas y formato de texto
  * Ámbitos (*scopes*), módulos y paquetes

* **02 - NumPy**
  * Introducción a NumPy y arreglos (*arrays*)
  * Operaciones, indexación y segmentación (*slicing*)
  * Reshape, apilamiento (*stacking*) y concatenación
  * Generación de números aleatorios y manejo de dimensiones

* **03 - Pandas**
  * Estructuras de datos (Series y DataFrames)
  * Importación/exportación y exploración de datos
  * Selección, asignación y manipulación de columnas
  * Agrupamientos (*groupby*) y fusiones (*merging*)

* **04 - Exploratory Data Analysis (EDA)**
  * Conceptos y exploración preliminar
  * Estadística descriptiva
  * Visualización de datos (Pandas, Matplotlib y Seaborn)
  * Resumen de funciones clave

* **05 - Data Preparation**
  * Identificación y manejo de datos faltantes (imputación con Scikit-Learn)
  * Escalado de características (*Feature Scaling*)
  * Parseo de fechas y corrección de inconsistencias

* **06 - Feature Engineering**
  * Manejo de variables categóricas y creación de métricas
  * Análisis de Componentes Principales (PCA)
  * Selección de características e información mutua (*Mutual Information*)

* **07 - Regression**
  * Aprendizaje supervisado y Regresión Lineal (simple, múltiple y polinomial)
  * División de datos (*Train-Validation-Test split*) y evaluación
  * Supuestos, sobreajuste (*overfitting*) y multicolinealidad
  * Técnicas de regularización, validación cruzada y k-NN Regresión

* **08 - Classification**
  * Regresión Logística (simple y multinomial)
  * Evaluación de modelos y fronteras de decisión
  * Regularización y k-NN Clasificación

* **09 - Decision Trees**
  * Funcionamiento y construcción de Árboles de Decisión
  * Manejo de conjuntos de datos desbalanceados
  * Métodos Ensemble: *Bagging*, *Random Forest* y *Boosting*

* **10 - Clustering**
  * Métricas de distancia y estandarización
  * Agrupamiento Jerárquico (*Hierarchical Clustering* y Dendrogramas)
  * K-Means y DBSCAN
  * Métricas de evaluación y selección del número óptimo de clústeres
