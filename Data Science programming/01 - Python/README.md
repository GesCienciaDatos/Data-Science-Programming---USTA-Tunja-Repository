## 📌 Descripción General

Este módulo proporciona los cimientos esenciales de la programación estructurada y orientada a objetos en **Python**, el lenguaje estándar de la industria para el análisis de datos, Machine Learning e Inteligencia Artificial.

A lo largo de este módulo desarrollarás el pensamiento algorítmico necesario para transformar lógica de negocio en código limpio, modular, mantenible y eficiente, dominando desde la sintaxis básica y estructuras nativas de datos hasta la gestión avanzada de memoria y modularización de proyectos.

## 🗺️ Estructura del Módulo

| # | Cuaderno | Temas Principales | Dificultad |
|---|---|---|:---:|
| **00** | [**Introducción y Conceptos Básicos**](00_Introduccion_y_Conceptos_Basicos.ipynb) | Pensamiento computacional, algoritmos, arquitectura de ejecución y el ecosistema de Python en Data Science. | 🟢 Básico |
| **01** | [**Sintaxis, Variables y Tipos de Datos**](01_Sintaxis_Variables_y_Tipos_de_Datos.ipynb) | Asignación de variables, operadores aritméticos/lógicos y tipos primitivos (`int`, `float`, `bool`, `str`). | 🟢 Básico |
| **02a** | [**Estructuras Nativas I: Listas, Tuplas y Conjuntos**](02a_Estructuras_Listas_Tuplas_Conjuntos.ipynb) | Colecciones indexadas, mutabilidad vs inmutabilidad, *slicing*, métodos de listas y operaciones de conjuntos. | 🟢 Básico |
| **02b** | [**Estructuras Nativas II: Diccionarios**](02b_Estructuras_Diccionarios.ipynb) | Estructuras clave-valor, tablas hash, métodos (`get`, `items`, `keys`, `values`) y diccionarios anidados. | 🟢 Básico |
| **03** | [**Flujo de Control**](03_Flujo_de_Control.ipynb) | Estructuras condicionales (`if/elif/else`), bucles (`for/while`), sentencias de control (`break`, `continue`, `pass`) y *List Comprehensions*. | 🟢 Básico |
| **04** | [**Funciones**](04_Funciones.ipynb) | Modularización, parámetros posicionales y nombrados, argumentos variables (`*args`, `**kwargs`), `docstrings` y funciones anónimas (`lambda`). | 🟡 Intermedio |
| **05** | [**Clases y Objetos**](05_Clases_y_Objetos.ipynb) | Programación Orientada a Objetos (POO), constructores (`__init__`), atributos de instancia/clase, métodos especiales y herencia. | 🧗 Avanzado |
| **06** | [**Manipulación de Cadenas de Texto**](06_Manipulacion_de_Cadenas_de_Texto.ipynb) | Métodos de cadenas (`split`, `join`, `strip`, `replace`), formateo con `f-strings` y limpieza de texto para análisis. | 🟢 Básico |
| **07** | [**Namespaces y Scopes**](07_Namespaces_y_Scopes.ipynb) | Ámbitos de variables, la regla de resolución **LEGB** (*Local, Enclosing, Global, Built-in*), palabras clave `global` y `nonlocal`. | 🧗 Avanzado |
| **08** | [**Módulos y Paquetes**](08_Modulos_y_Paquetes.ipynb) | Importaciones (`import`, `from ... import`), creación de módulos propios, archivos `__init__.py` y paquetes estándar (`math`, `random`, `datetime`, `os`, `sys`). | 🟡 Intermedio |
