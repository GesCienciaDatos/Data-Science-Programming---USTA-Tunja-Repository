## 📌 Descripción General

Esta carpeta contiene los **Talleres Prácticos Evaluativos (*Hands-On Homeworks*)** diseñados para consolidar los conocimientos adquiridos en cada uno de los módulos teóricos del curso mediante problemas y conjuntos de datos reales.

A diferencia de los cuadernos de clase (que incluyen soluciones interactivas desplegables), estos talleres están orientados a que el estudiante resuelva los retos de forma autónoma, aplicando buenas prácticas de desarrollo de software, análisis exploratorio y modelado predictivo.

## 📋 Instrucciones y Criterios de Entrega

1. **Entorno de Ejecución:** Asegúrate de ejecutar los cuadernos en un entorno virtual con las dependencias requeridas (Python 3.9+, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn).
2. **Ejecución Completa:** Antes de la entrega, reinicia el kernel y ejecuta todas las celdas (*Restart Kernel and Run All Cells*) para verificar que no existan errores de ejecución.
3. **Claridad y Documentación:** Agrega comentarios explicativos en español en tu código cuando sea necesario para justificar decisiones analíticas o transformaciones estadísticas.
