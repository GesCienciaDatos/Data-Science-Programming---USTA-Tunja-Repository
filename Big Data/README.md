## 📌 Descripción de la Asignatura

Arquitecturas y paradigmas de computación distribuida para el procesamiento de datos masivos: Ecosistema Apache Spark (PySpark, Spark SQL, Structured Streaming), Hadoop HDFS, bases de datos masivas distribuidas y computación en la nube (AWS / GCP / Azure).
