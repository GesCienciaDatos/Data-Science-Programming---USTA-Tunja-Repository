## 📚 Estructura Curricular del Módulo

### 🎓 1. Cuadernos Académicos Estándar:
1. [**00_Introduccion_a_Big_Data_y_Computacion_Distribuida.ipynb**](00_Introduccion_a_Big_Data_y_Computacion_Distribuida.ipynb): Las 5 V's del Big Data, límites de la RAM mononodo y modelo MapReduce.
2. [**01_Arquitectura_Apache_Spark_y_PySpark.ipynb**](01_Arquitectura_Apache_Spark_y_PySpark.ipynb): Driver, Executors, SparkSession, RDDs, DataFrames y Catalyst Optimizer.
3. [**02_ETL_y_Preprocesamiento_Distribuido_con_Spark.ipynb**](02_ETL_y_Preprocesamiento_Distribuido_con_Spark.ipynb): Transformaciones perezosas (*Lazy Evaluation*), acciones, lectura de grandes volúmenes y agregaciones distribuidas.
4. [**03_Mineria_de_Datos_con_Spark_MLlib.ipynb**](03_Mineria_de_Datos_con_Spark_MLlib.ipynb): Pipelines de Machine Learning distribuido, `VectorAssembler`, Clustering y Clasificación a escala masiva.
5. [**04_Streaming_y_Mineria_en_Tiempo_Real.ipynb**](04_Streaming_y_Mineria_en_Tiempo_Real.ipynb): Structured Streaming, micro-lotes (*micro-batches*), ventanas deslizantes y detección de anomalías en tiempo real.

### 📝 2. Taller Práctico Evaluativo (*Hands-On*):
* [**homeworks/07_Big_Data_Mining_Hands_On.ipynb**](homeworks/07_Big_Data_Mining_Hands_On.ipynb): Pipeline de minería distribuida sobre logs masivos de tráfico web.
