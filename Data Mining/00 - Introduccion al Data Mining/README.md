## 🧭 ¿Qué es la Minería de Datos?

La Minería de Datos (*Data Mining*) es el proceso computacional y estadístico no trivial orientado al descubrimiento de patrones válidos, novedosos, potencialmente útiles y comprensibles a partir de repositorios masivos de datos (Fayyad et al., 1996). 

Constituye la piedra angular entre la ingeniería de datos, el análisis exploratorio y los modelos avanzados de inteligencia artificial.
