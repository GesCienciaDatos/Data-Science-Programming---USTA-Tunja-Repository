# Módulo 3: Análisis de Datos con Pandas

Este módulo enseña cómo utilizar Pandas para el manejo, limpieza y análisis estructurado de datos tabulares.

## Contenido

- Series y DataFrames
- Importación y exportación de datos (CSV, Excel)
- Limpieza de datos (Manejo de nulos, duplicados)
- Agrupación (GroupBy) y tablas dinámicas
- Transformaciones y filtrados complejos
