# Módulo 3: Análisis de Datos con Pandas

Este módulo enseña cómo utilizar Pandas para el manejo, limpieza, transformación y análisis estructurado de datos tabulares y series de datos heterogéneos.

## Contenido

1. **[Introducción a Pandas](00_Introduccion_Pandas.ipynb)**: Filosofía de diseño, ventajas sobre NumPy y estructuras tabulares.
2. **[Estructuras de Datos de Pandas](01_Estructuras_de_Datos_Pandas.ipynb)**: Series unidimensionales y DataFrames bidimensionales.
3. **[Importación y Exportación de Datos](02_Importacion_y_Exportacion_Pandas.ipynb)**: Lectura y escritura en CSV, Excel, JSON y Parquet.
4. **[Exploración de Datos](03_Exploracion_de_Datos_Pandas.ipynb)**: Diagnóstico rápido con `.info()`, `.describe()`, `.head()` y `.value_counts()`.
5. **[Indexación y Selección de Datos](04_Indexacion_y_Seleccion_Pandas.ipynb)**: Filtrado con `loc`, `iloc` y máscaras booleanas.
6. **[Asignación y Modificación de Datos](05_Asignacion_de_Datos_Pandas.ipynb)**: Modificación de valores, operaciones condicionales y control de copias.
7. **[Añadir y Eliminar Columnas](06_Añadir_y_Eliminar_Columnas_Pandas.ipynb)**: Creación de variables calculadas, `insert` y `drop`.
8. **[Agrupación y Ordenamiento](07_Agrupacion_y_Ordenamiento_Pandas.ipynb)**: Agrupaciones con `groupby`, agregaciones (`agg`) y `sort_values`.
9. **[Fusión de Datos (Merge, Join, Concat)](08_Fusion_de_Datos_Pandas.ipynb)** 🧗: Cruces relacionales estilo SQL (Inner, Left, Right, Outer) y concatenaciones.
