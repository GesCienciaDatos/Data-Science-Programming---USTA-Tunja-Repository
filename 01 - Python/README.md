# Módulo 1: Fundamentos de Programación con Python

Este módulo cubre los fundamentos esenciales del lenguaje de programación Python orientados al análisis, manipulación y la Ciencia de Datos.

## Contenido

1. **[Introducción y Conceptos Básicos](00_Introduccion_y_Conceptos_Basicos.ipynb)**: Pensamiento computacional, algoritmos y el rol de Python en Data Science.
2. **[Sintaxis, Variables y Tipos de Datos](01_Sintaxis_Variables_y_Tipos_de_Datos.ipynb)**: Variables, operadores y tipos primitivos (`int`, `float`, `bool`, `str`).
3. **[Estructuras Nativas I: Listas, Tuplas y Conjuntos](02a_Estructuras_Listas_Tuplas_Conjuntos.ipynb)**: Colecciones ordenadas, inmutables y conjuntos no duplicados.
4. **[Estructuras Nativas II: Diccionarios](02b_Estructuras_Diccionarios.ipynb)**: Estructuras clave-valor y mapeo eficiente.
5. **[Flujo de Control](03_Flujo_de_Control.ipynb)**: Condicionales (`if/elif/else`) y ciclos de repetición (`for/while`).
6. **[Funciones](04_Funciones.ipynb)**: Modularización, paso de parámetros (`*args`, `**kwargs`) y funciones lambda.
7. **[Clases y Objetos](05_Clases_y_Objetos.ipynb)** 🧗: Programación Orientada a Objetos (POO), métodos especiales y encapsulamiento.
8. **[Manipulación de Cadenas de Texto](06_Manipulacion_de_Cadenas_de_Texto.ipynb)**: Métodos de formateo, `f-strings` y limpieza de texto.
9. **[Namespaces y Scopes](07_Namespaces_y_Scopes.ipynb)** 🧗: La regla LEGB y gestión de variables en memoria.
10. **[Módulos y Paquetes](08_Modulos_y_Paquetes.ipynb)**: Organización de proyectos y uso de la biblioteca estándar de Python.
