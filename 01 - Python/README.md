# Módulo 01: Introducción a la Programación con Python

Bienvenido al primer módulo de **Programación para Ciencia de Datos (USTA Tunja)**. En esta lección aprenderás las bases del lenguaje Python, sus estructuras de datos fundamentales y la lógica de programación necesaria para el análisis de datos.

## 🎯 Objetivos de aprendizaje

En este primer módulo sentaremos las bases fundamentales del lenguaje Python, con un enfoque 100% orientado al análisis y la Ciencia de Datos. El material está organizado de forma progresiva en los siguientes cuadernos interactivos:

1. **[Introducción y Conceptos Básicos](00_Introduccion_y_Conceptos_Basicos.ipynb)**: ¿Qué es la programación y por qué Python es el líder indiscutible en Data Science?
2. **[Sintaxis, Variables y Tipos de Datos](01_Sintaxis_Variables_y_Tipos_de_Datos.ipynb)**: Reglas de escritura, declaración de variables, operadores y tipos primitivos.
3. **[Estructuras Nativas I: Listas, Tuplas y Conjuntos](02a_Estructuras_Listas_Tuplas_Conjuntos.ipynb)**: Manejo de colecciones de datos fundamentales.
4. **[Estructuras Nativas II: Diccionarios](02b_Estructuras_Diccionarios.ipynb)**: Estructuras clave-valor para mapeo ultrarrápido de información.
5. **[Flujo de Control](03_Flujo_de_Control.ipynb)**: Dotando de inteligencia a nuestros algoritmos mediante condicionales (`if`) y bucles (`for`/`while`).
6. **[Funciones](04_Funciones.ipynb)**: Empaquetamiento, abstracción y reutilización de código analítico.
7. **[Clases y Objetos](05_Clases_y_Objetos.ipynb)**: Fundamentos de la Programación Orientada a Objetos (POO) en el ecosistema Python.
8. **[Manipulación de Cadenas de Texto](06_Manipulacion_de_Cadenas_de_Texto.ipynb)**: Técnicas de limpieza y formateo de *strings*, paso vital en la limpieza de datos (Data Cleaning).
9. **[Namespaces y Scopes](07_Namespaces_y_Scopes.ipynb)**: La regla LEGB y el manejo interno de variables en memoria.
10. **[Módulos y Paquetes](08_Modulos_y_Paquetes.ipynb)**: Organización de proyectos y uso de la vasta librería estándar.
