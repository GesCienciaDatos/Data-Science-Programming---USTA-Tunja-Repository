📐 Regresión Lineal OLS

Ecuación Normal de Mínimos Cuadrados Ordinarios:

θ = (XT X)-1 XT y
  • MSE: Error Cuadrático Medio = (1/n) ∑ (yi - ŷi)2
  • R²: Coeficiente de Determinación = 1 - (SSres / SStot)
  • Interpretación: βj = cambio en y por unidad en xj ceteris paribus.

🔍 Supuestos de Gauss-Markov

Para que OLS sea el mejor estimador lineal insesgado (BLUE):

  • Linealidad: Relación lineal en los parámetros.
  • Homocedasticidad: Varianza constante de los residuos (Var(ε) = σ²).
  • Normalidad: Residuos distribuidos normalmente ε ~ N(0, σ²).
  • Independencia: Sin autocorrelación serial (Durbin-Watson ≈ 2).
  • Sin Multicolinealidad: VIFj < 5 (VIF = 1 / (1 - Rj²)).

⚖️ Técnicas de Regularización

Control de sobreajuste y complejidad:

  • Ridge (L2): Minimiza MSE + λ ∑ βj² (encoge coeficientes hacia cero).
  • Lasso (L1): Minimiza MSE + λ ∑ |βj| (genera dispersión y selección automática).
  • ElasticNet: Combina L1 y L2 con ponderación r.
  • Regla de Oro: ¡Siempre estandarizar variables antes de regularizar!

🔄 Cross-Validation y Pipelines

Buenas prácticas contra Data Leakage:

  • k-Fold CV: Divide en k pliegues y promedia las métricas de prueba.
  • Pipeline: Encapsula escaladores y transformadores dentro de cada pliegue.
  • Scikit-Learn: La API siempre maximiza scores (MSE se devuelve negativo).
  • k-NN: Requiere escalado obligatorio MinMaxScaler / StandardScaler.
