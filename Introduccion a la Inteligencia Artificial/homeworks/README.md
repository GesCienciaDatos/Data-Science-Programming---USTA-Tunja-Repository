## 📌 Descripción General

Esta carpeta contiene los **Talleres Prácticos Evaluativos (*Hands-On Homeworks*)** diseñados para consolidar los conocimientos adquiridos en cada uno de los módulos teóricos del curso **Introducción a la Inteligencia Artificial**.

A diferencia de los cuadernos de clase, estos talleres están orientados a que el estudiante resuelva los retos de forma **autónoma**: cada notebook plantea un enunciado claro y una celda de código con andamiaje (`# TODO:`) que el estudiante debe completar, sin soluciones ya resueltas.

Cada taller tiene además una versión **"Para Dummies"** 🧸 disponible en la subcarpeta [`Para Dummies/`](Para%20Dummies/), pensada para estudiantes que necesiten una guía más detallada, con más pistas y ejemplos parcialmente resueltos antes de cada reto — pero que siguen exigiendo que el estudiante resuelva el ejercicio por sí mismo.

## 📋 Instrucciones y Criterios de Entrega

1. **Entorno de Ejecución:** ejecuta los cuadernos en un entorno virtual con Python 3.9+ y las dependencias requeridas (NumPy, Pandas, Matplotlib).
2. **Ejecución Completa:** antes de la entrega, reinicia el kernel y ejecuta todas las celdas (*Restart Kernel and Run All Cells*) para verificar que no existan errores de ejecución.
3. **Resolución Autónoma:** completa únicamente las celdas marcadas con `# TODO:`. No se aceptan notebooks con celdas de reto sin completar.
4. **Documentación:** agrega comentarios explicativos en español en tu código cuando sea necesario para justificar tus decisiones de diseño.
5. **Versión Para Dummies:** si tomas la ruta guiada (`Para Dummies/`), recuerda que sigue siendo un taller evaluativo: complétalo por tu cuenta, apoyándote solo en las pistas y ejemplos ya provistos en el propio notebook.
