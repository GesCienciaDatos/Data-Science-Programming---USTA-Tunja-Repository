## 📌 Descripción de la Asignatura

Analítica visual interactiva con enfoque triángulo **Python ↔ Power BI ↔ Tableau**: narrativa con datos (*Data Storytelling*), diseño perceptual de tableros de control, sesgos cognitivos en la interpretación visual y pensamiento crítico para la toma de decisiones estratégicas. Se incluye una sección dedicada a **Power Query** como herramienta de transformación y preparación de datos.

---

## 🧭 Introducción al Espacio Académico

Este espacio reúne los cuadernos, talleres y recursos de la asignatura **Visual Analytics and Critical Thinking**, construidos sobre dos capítulos correlativos: **Fundamentos del Análisis y Visualización de Datos** (percepción, diseño y pensamiento crítico) y **Técnicas Avanzadas y Aplicaciones de Visualización de Datos** (visualización numérica, avanzada y casos de estudio reales). Cada sección numerada del programa oficial tiene su propio cuaderno estándar y su versión **Para Dummies**, siguiendo la misma convención de granularidad usada en las demás asignaturas del repositorio (Data Mining, Introducción a la Inteligencia Artificial).

## 🔺 Enfoque Triángulo Python ↔ Power BI ↔ Tableau

Cada tema se aborda desde tres perspectivas complementarias:

```
        🐍 Python
       (Matplotlib
       Seaborn · Plotly
       Dash · Streamlit)
            /\
           /  \
          /    \
         /      \
        /________\
  📊 Power BI   📈 Tableau
  (Desktop/Service) (Public/Desktop)
```

Los notebooks en Python son **100% ejecutables** en Google Colab. Las secciones de Power BI y Tableau incluyen tablas de mapeo, comparativas y guías paso a paso; el módulo 02 ("Herramientas: Tableau, Power BI, D3.js") enlaza directamente al taller práctico de **Power Query** para la profundización en el motor ETL de Power BI.
