## 📌 Descripción de la Asignatura

Analítica visual interactiva, narrativa con datos (*Data Storytelling*), diseño perceptual de tableros de control (Dashboards con Plotly/Dash/Streamlit), sesgos cognitivos en la interpretación visual y pensamiento crítico para la toma de decisiones estratégicas.
