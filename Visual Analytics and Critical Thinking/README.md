## 📌 Descripción de la Asignatura

Analítica visual interactiva con enfoque triángulo **Python ↔ Power BI ↔ Tableau**: narrativa con datos (*Data Storytelling*), diseño perceptual de tableros de control, sesgos cognitivos en la interpretación visual y pensamiento crítico para la toma de decisiones estratégicas. Se incluye una sección dedicada a **Power Query** como herramienta de transformación y preparación de datos.

## 🔺 Enfoque Triángulo Python ↔ Power BI ↔ Tableau

Cada tema se aborda desde tres perspectivas complementarias:

```
        🐍 Python
       (Matplotlib
       Seaborn · Plotly
       Dash · Streamlit)
            /\
           /  \
          /    \
         /      \
        /________\
  📊 Power BI   📈 Tableau
  (Desktop/Service) (Public/Desktop)
```

Los notebooks en Python son **100% ejecutables** en Google Colab. Las secciones de Power BI y Tableau incluyen tablas de mapeo, capturas descriptivas y guías paso a paso.
