## 📌 Descripción de la Asignatura

Estrategias modernas de extracción y recolección de datos (APIs REST, Web Scraping, ingesta de streams), modelado de bases de datos relacionales y NoSQL, arquitecturas de Data Lakes, calidad de datos y marcos de gobernanza (DAMA-DMBOK, linaje y cumplimiento regulatorio).
